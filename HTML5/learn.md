# HTML 学习路线（MDN 中文）

> 使用说明：按顺序学习。每一步都建议在 WebStorm 中写 Demo，并提交到 GitHub。
> 如果某个中文链接打不开，可把链接中的 `/zh-CN/` 改成 `/en-US/`。

## 总入口

- [使用 HTML 构建 Web（MDN 学习区）](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content>)
- [MDN 学习区：核心模块](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core>)

---

## 第一阶段：HTML 基础

### 1. HTML 基础语法

- 链接：[Basic HTML syntax](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax>)
- 目标：理解标签、元素、属性、文档结构。
- 练习：用 WebStorm 写一个包含标题、段落、注释的页面。

### 2. 头部元数据

- 链接：[What is in the head?](<https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/head>)
- 目标：掌握 `<head>`、`<meta>`、`<title>`、字符集、视口。
- 练习：给页面设置标题、描述、`charset`、`viewport`。

### 3. 标题和段落

- 链接：[Headings and paragraphs](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Headings_and_paragraphs>)
- 目标：正确使用 `<h1>`~`<h6>`、`<p>`、`<br>`、`<hr>`。
- 练习：写一篇结构清晰的文章，包含多级标题和段落。

### 4. 列表

- 链接：[Lists](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Lists>)
- 目标：掌握 `<ul>`、`<ol>`、`<li>`、`<dl>`、`<dt>`、`<dd>`。
- 练习：制作导航列表、步骤列表、术语表。

### 5. 链接

- 链接：[Creating hyperlinks](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Creating_hyperlinks>)
- 目标：掌握 `<a>`、`href`、相对路径、绝对路径、锚点、`target`。
- 练习：做一个包含站内链接、站外链接、邮件链接、锚点链接的页面。

### 6. 高级文本格式

- 链接：[Advanced text formatting](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Advanced_text_formatting>)
- 目标：`<strong>`、`<em>`、`<blockquote>`、`<q>`、`<cite>`、`<abbr>`、`<code>`、`<pre>`。
- 练习：写一段带引用、缩写、代码、强调的文本。

### 7. 文档和网站结构

- 链接：[Document and website structure](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Document_and_website_structure>)
- 目标：用 `<header>`、`<nav>`、`<main>`、`<section>`、`<article>`、`<aside>`、`<footer>` 组织页面。
- 练习：搭建一个个人主页的语义化结构。

### 8. 调试 HTML

- 链接：[Debugging HTML](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Debugging_HTML>)
- 目标：学会用浏览器开发者工具和 W3C 验证器排查 HTML 错误。
- 练习：故意写错几个标签，用验证器找出并修复。

### 9. 评估：标记一封信

- 链接：[Assessment: Marking up a letter](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Marking_up_a_letter>)
- 目标：综合运用文本、列表、链接、语义标签。
- 练习：按 MDN 要求完成评估任务。

### 10. 评估：构建页面内容

- 链接：[Assessment: Structuring a page of content](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Structuring_a_page_of_content>)
- 目标：综合运用文档结构、导航、文章、页脚。
- 练习：完成一个完整页面结构评估。

## 第二阶段：多媒体和嵌入

### 11. 图片

- 链接：[Images](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Images>)
- 目标：`<img>`、`src`、`alt`、宽高、`figure`、`figcaption`。
- 练习：给个人主页加入头像和作品截图。

### 12. 视频和音频内容

- 链接：[Video and audio content](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Video_and_audio_content>)
- 目标：`<video>`、`<audio>`、`controls`、`<source>`、字幕。
- 练习：嵌入一个本地视频和音频，带控制条。

### 13. 从对象到 iframe

- 链接：[From object to iframe](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/From_object_to_iframe>)
- 目标：`<iframe>`、嵌入地图、视频、其他网页。
- 练习：嵌入一个地图或在线视频。

### 14. 为 Web 添加矢量图形

- 链接：[Adding vector graphics to the Web](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Adding_vector_graphics_to_the_Web>)
- 目标：SVG 基础、`<svg>`、内联 SVG、`<img>` 引入 SVG。
- 练习：画一个简单图标并嵌入页面。

### 15. 响应式图片

- 链接：[Responsive images](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Responsive_images>)
- 目标：`srcset`、`sizes`、`<picture>`、不同分辨率适配。
- 练习：为同一张图准备多种尺寸，适配手机和桌面。

## 第三阶段：HTML 表格

### 16. HTML 表格基础

- 链接：[HTML table basics](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/HTML_table_basics>)
- 目标：`<table>`、`<tr>`、`<td>`、`<th>`、`<caption>`、合并单元格。
- 练习：制作课程表或成绩表。

### 17. HTML 表格高级特性和无障碍

- 链接：[HTML table advanced features and accessibility](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/HTML_table_advanced_features_and_accessibility>)
- 目标：`<thead>`、`<tbody>`、`<tfoot>`、`scope`、`id`/`headers`。
- 练习：给表格加表头、页脚和无障碍属性。

### 18. 评估：构建行星数据

- 链接：[Assessment: Structuring planet data](<https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Structuring_planet_data>)
- 目标：综合运用表格标记和无障碍。
- 练习：按 MDN 要求完成行星数据表格。

## 学习节奏建议

- 每天 1~2 小时，周末 3~4 小时。
- 每个知识点：读 MDN → 在 WebStorm 写 Demo → 提交 Git。
- 每完成一个阶段，做一个小项目：
  - 阶段一：个人主页静态结构
  - 阶段二：带图片、视频、地图的主页
  - 阶段三：课程表或数据表格页面
- 不要追求一次记住所有标签，知道“有什么、去哪查”即可。
